    04 — Feedback

    Tell us what's missing.

    One form for everything: a paper that should be there, a timetable that has changed, a photo that belongs in Moments, or a page you wish existed.

    The feedback form

    It opens in a new tab. No sign-in, and the name field is optional — send it anonymously if you would rather, it still gets read.

    Open the feedback form ↗ Responses land in a spreadsheet the CR checks every Sunday.

    Sending a file? Paste a Drive link set to "anyone with the link". Private links cannot be opened, so the request just sits there.

    Good feedback looks like

    • Name the page, then say what is wrong: "Resources, the 2nd semester folder is empty."
    • One topic per message, so it can be acted on and ticked off.
    • A link beats a description when you are sending a paper or a book.
